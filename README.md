# Bot de WhatsApp - FINANCIERA CREFICER

Bot para envío programado de recordatorios de cobro y atención automatizada vía WhatsApp con Baileys.

## Instalación local
1. Descomprime el archivo.
2. Abre la terminal en la carpeta y ejecuta:
   ```bash
   npm install
   npm start
   ```
3. Escanea el código QR que aparecerá en pantalla.

## Despliegue en Railway
1. Sube estos archivos a un repositorio de GitHub.
2. En Railway selecciona **Deploy from GitHub repo**.
3. Revisa los logs de Railway y escanea el QR desde tu WhatsApp.
